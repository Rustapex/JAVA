## 5. 실행 방법

이 저장소는 여러 개의 Java 실습 파일이 포함된 학습용 저장소입니다.  
저장소 전체를 하나의 프로그램처럼 실행하는 구조가 아니라, 실행하려는 Java 파일을 개별적으로 실행합니다.

### 5-1. 저장소 클론

```bash
git clone https://github.com/Rustapex/JAVA.git
cd JAVA
```

### 5-2. IDE에서 실행

Eclipse 또는 Java 실행이 가능한 IDE에서 프로젝트 또는 폴더를 import합니다.

```text
File → Import → Existing Projects into Workspace
```

### 5-3. Java 파일 실행

실행하려는 클래스의 `main()` 메서드를 실행합니다.

```text
Run As → Java Application
```

### 5-4. 터미널 실행 예시

```bash
javac 파일명.java
java 클래스명
```

## 6. 구현 및 학습 포인트

### 6-1. Java 기초 문법을 작은 예제로 분리

* Java 기본 문법을 하나의 큰 프로젝트가 아니라 작은 예제로 나누어 실습했습니다.
* 변수, 조건문, 반복문, 배열, 메서드 등을 콘솔 출력으로 확인했습니다.
* 개념별로 코드를 직접 작성하면서 Java 문법의 동작 방식을 익혔습니다.

### 6-2. 콘솔 입출력과 알고리즘 풀이

* `Scanner`, `StringTokenizer` 등을 사용하여 콘솔 입력을 처리했습니다.
* solved.ac / BOJ 문제를 통해 입력, 처리, 출력의 기본 흐름을 반복적으로 연습했습니다.
* Java로 문제를 읽고 해결하는 기본적인 문제 풀이 방식을 학습했습니다.

### 6-3. 객체지향 기초 실습

* 클래스, 필드, 생성자, 메서드를 사용하여 객체를 생성하고 활용하는 방식을 실습했습니다.
* 상속, 인터페이스, 다형성 등 객체지향의 기본 개념을 예제로 확인했습니다.
* 이후 웹 프로그래밍과 Spring 학습으로 넘어가기 위한 Java 기반을 다졌습니다.

### 6-4. 예외 처리와 스레드 기초

* 예외가 발생할 수 있는 상황과 처리 흐름을 실습했습니다.
* Thread 관련 기초 예제를 통해 프로그램 흐름이 동시에 실행되는 구조를 확인했습니다.
* 실무적인 완성도보다는 Java 문법 이해에 초점을 두었습니다.
